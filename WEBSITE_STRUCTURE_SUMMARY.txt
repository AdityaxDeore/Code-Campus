================================================================================
1. PROJECT IDEA & PURPOSE
================================================================================
CodeCampus is a comprehensive academic coding education platform designed for
computer science university students. Its mission is to help students:
  - Solve coding problems (LeetCode-style)
  - Complete assignments in a VS Code-style browser IDE
  - Take proctored tests with anti-cheating measures
  - Collaborate on forums (Twitter/Reddit-style)
  - Track achievements, badges, streaks, and leaderboards
  - Follow guided learning pathways
  - Showcase projects and build portfolios
  - Prepare for tech interviews

Target audience: CS university students from colleges worldwide.
Tagline: "Your Code, Your Community, Your Career"

================================================================================
2. TECH STACK & FRAMEWORKS
================================================================================
Frontend:
  - React 18 (hooks, Suspense, lazy loading, code splitting)
  - Vite 5 (fast dev server, optimized production builds)
  - React Router 6 (client-side routing, protected routes, basename="/codecampus")
  - TailwindCSS (utility-first CSS, custom theme, dark mode, responsive)
  - Monaco Editor (@monaco-editor/react) — the VS Code editor engine
  - Framer Motion (animations, transitions, scroll-triggered effects)
  - React Helmet (SEO meta tags per page)
  - Radix UI (accessible primitives, e.g. Slot for Button)
  - class-variance-authority (cva) for button variant management
  - styled-components (used for DarkModeToggle animation)
  - Lucide React icons via AppIcon wrapper

Backend:
  - Firebase Authentication (email/password sign-in/sign-up)
  - Firebase Firestore (database, real-time features)
  - Express.js server (in /server/) for assignment/submission CRUD via MongoDB
  - MongoDB (Assignment and Submission models)

Build & Deploy:
  - Vite for builds, output in /build/
  - Docker + docker-compose + nginx for production
  - PostCSS + TailwindCSS plugins (forms, typography, aspect-ratio, container queries)

3. VISUAL DESIGN SYSTEM
================================================================================
Color Palette:
  - Primary: Blue (#3B82F6, --color-primary)
  - Accent/Secondary: Emerald/Green
  - Background (light): White / #f7f8fa
  - Background (dark): Gray-900 / #1e1e1e (OLED dark)
  - Foreground: Slate-900 (light), #e0e0e0 (dark)
  - Muted: Slate-400/500
  - Error: Red-500/600
  - Warning: Amber-500/600
  - Success: Emerald-500/600

Dark Mode:
  - Toggle via DarkModeContext (React Context)
  - Stored in localStorage under "darkMode"
  - Applies "dark" + "oled-dark" classes to <html>
  - All components use dark: TailwindCSS variants
  - Toggle UI: Animated slider with Sun/Moon emoji icons

Typography:
  - Font: System font stack via Tailwind defaults
  - Code: JetBrains Mono, Fira Code, monospace
  - Sizes: text-[10px] to text-5xl, fluid responsive

Shadows & Borders:
  - Subtle shadows: box-shadow: 0 1px 2px rgba(0,0,0,.04)
  - Card borders: border-slate-200/80
  - VS Code panels: border-[#3c3c3c] on dark backgrounds

Animations:
  - Framer Motion: fade-in, slide-in, scale on scroll (whileInView)
  - Typing animation on homepage hero (code typewriter effect)
  - Pulse animations on login page floating elements
  - Hover scale-105 on achievement cards
  - Smooth transitions on all buttons and links (transition-colors duration-200)
  - Progress bar animations (transition: width .4s)

Responsive:
  - Mobile-first with sm:, md:, lg: Tailwind breakpoints
  - Hamburger mobile menu in Header
  - Grid layouts collapse to single column on mobile
  - Container max-widths: max-w-[1200px], max-w-[1100px], max-w-[900px]

  - Submit button: full-width, blue bg, loading spinner when submitting

User Flow:
  1. User visits /login
  2. If already authenticated (Firebase), auto-redirects to /student-dashboard

  4. On success: stores in localStorage + navigates to /student-dashboard
  5. On error: shows specific error message (email exists, wrong password, etc.)

Buttons:
  - Sign In tab toggle
  - Sign Up tab toggle
  - Submit (Sign In / Create Account) — primary, full-width, loading state
  - CodeCampus logo link → /homepage

7. AUTHENTICATION & SECURITY
================================================================================
- Firebase Authentication (email/password)
- ProtectedRoute component guards all authenticated pages
- onAuthStateChange listener for real-time auth state
- localStorage stores: isAuthenticated, userEmail, userName, loginMethod
- Sign out: Firebase signOut + clear localStorage + redirect to /login
- Academic integrity system:
  - Paste detection hook (usePasteDetection): word/char threshold, policy (allow/warn/block)
  - Exam mode hook (useExamMode): fullscreen, tab switch, devtools, right-click blocking
  - Integrity logger: logs all events, generates report on submission

================================================================================
8. CONTEXTS & STATE MANAGEMENT
================================================================================
- DarkModeContext: isDarkMode state, toggleDarkMode function, localStorage persistence
- RoleContext: user role management (student/teacher)
- Component-level state via useState/useEffect hooks
- No Redux or global state library — state is per-page with React hooks

================================================================================
9. HOOKS (Custom)
================================================================================
- useAuth: Firebase auth state management
- useExamMode: Fullscreen, tab detection, devtools detection, auto-submit
- usePasteDetection: Paste event interception, word counting, content hashing

12. USER FLOWS (End-to-End)
================================================================================

FLOW 1: New Student Registration
  /homepage → click "Start Coding Now" → /login (redirected, not authenticated)
  → click "Sign Up" tab → fill name, email, password → Submit
  → Firebase creates account → redirect to /student-dashboard

FLOW 2: Solve a Problem
  /student-dashboard → click "Code Editor" → /problem-workspace
  → select problem → read description → write code → click "Run Code"
  → see test results → fix code → click "Submit" → success animation

FLOW 3: Complete an Assignment
  /student-dashboard → click assignment "Continue" → /assignment-workspace?id=a1
  → browse files in explorer → edit code in Monaco Editor → run in terminal
  → use AI assistant for hints → click Submit → confirmation → submitted

FLOW 4: Take a Proctored Test
  /student-dashboard → click "Tests" quick nav → /test
  → click "Start Test" → enters fullscreen → solve questions
  → navigate between questions → click "End Test" → submitted

FLOW 5: Browse Forums
  /student-dashboard → click "Forums" → /campus-forums
  → browse posts → like/comment/share → create new post
